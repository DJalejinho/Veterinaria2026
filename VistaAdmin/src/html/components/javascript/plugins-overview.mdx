AdminLTE incluye ocho complementos de JavaScript en un único paquete (`adminlte.js`). Cada uno se exporta desde la raíz del paquete, se puede activar mediante atributos `data-lte-*` y ofrece una API programática para controlarlo desde el código.

##### Resumen

| Complemento | API de datos | API programática | Documentación |
|---|---|---|---|
| **Menú lateral** | `data-lte-toggle="sidebar"` | `.toggle()` / `.expand()` / `.collapse()` | [Referencia](pushmenu.html) |
| **Treeview** | `data-lte-toggle="treeview"` en el menú principal | `.toggle()` / `.open()` / `.close()` | [Referencia](treeview.html) |
| **CardWidget** | `data-lte-toggle="card-collapse"`, `card-remove`, `card-maximize` | `.toggle()` / `.collapse()` / `.expand()` / `.remove()` / `.maximize()` / `.minimize()` / `.toggleMaximize()` | [Referencia](card-widget.html) |
| **DirectChat** | `data-lte-toggle="chat-pane"` | `.toggle()` | [Referencia](direct-chat.html) |
| **FullScreen** | `data-lte-toggle="fullscreen"` | `.toggleFullScreen()` / `.inFullScreen()` / `.outFullScreen()` | [Referencia](fullscreen.html) |
| **SidebarSearch** | `data-lte-toggle="sidebar-search"` en un campo de entrada | `.search(term)` / `.clear()` | [Referencia](sidebar-search.html) |
| **Layout** | (se aplica automáticamente a `<body>`) | `.holdTransition(time)` | [Referencia](layout.html) |
| **AccessibilityManager** | (función auxiliar: `initAccessibility()`) | `.announce()` / `.focusElement()` / `.trapFocus()` / `.addLandmarks()` | [Referencia](accessibility.html) |

##### Dos formas de usarlos

###### 1. API de datos (declarativa)

En la mayoría de las páginas basta con la API de datos; no hace falta escribir JavaScript. Añade el atributo `data-lte-*` correspondiente al elemento de activación y el paquete lo configurará al cargar la página:

```html
<!-- Control de la barra lateral -->
<button data-lte-toggle="sidebar">☰</button>

<!-- Contraer, eliminar o maximizar tarjeta -->
<div class="card">
  <div class="card-header">
    <h3 class="card-title">Título</h3>
    <div class="card-tools">
      <button class="btn btn-tool" data-lte-toggle="card-collapse" aria-label="Contraer tarjeta">
        <i data-lte-icon="expand" class="bi bi-dash-lg"></i>
        <i data-lte-icon="collapse" class="bi bi-plus-lg"></i>
      </button>
    </div>
  </div>
  <div class="card-body">…</div>
</div>
```

El paquete conecta todos los controladores de la API de datos en `DOMContentLoaded`. Los elementos insertados dinámicamente también funcionan con los complementos [Menú lateral](pushmenu.html), [CardWidget](card-widget.html), [Treeview](treeview.html) y [SidebarSearch](sidebar-search.html), que usan delegación de eventos.

###### 2. Mediante código (imperativa)

Cuando necesites controlar un complemento desde tu código —por ejemplo, abrir la barra lateral después de iniciar sesión o expandir una tarjeta al cambiar de ruta—, recupera la instancia que ya creó la API de datos o crea una cuando la necesites (desde la versión 4.1):

```js
// ESM (importación con empaquetador)
import { PushMenu, CardWidget } from "admin-lte"

// Barra lateral: la API de datos crea la instancia al cargar; solo hay que recuperarla
const sidebar = document.querySelector(".app-sidebar")
PushMenu.getInstance(sidebar)?.expand()

// Maximizar tarjeta: reutiliza la instancia existente o crea una
const card = document.querySelector("#chart-card")
CardWidget.getOrCreateInstance(card).maximize()
```

También puedes usar las variables globales (paquete UMD, sin compilación):

```html
<script>
  // El paquete asigna la instancia a window.adminlte
  adminlte.PushMenu.getInstance(document.querySelector(".app-sidebar"))?.expand()
</script>
```

###### Ciclo de vida del componente

Todos los componentes siguen el mismo contrato que Bootstrap:

- `Component.getInstance(element)` — instancia creada para ese elemento o `null`.
- `Component.getOrCreateInstance(element, config?)` — reutiliza o crea una instancia (la configuración solo se aplica al crearla).
- `instance.dispose()` — elimina el registro de la instancia; después, `getInstance()` devuelve `null`.

Se conserva una instancia por elemento en un registro basado en `WeakMap`, así que el recolector de basura elimina las instancias junto con sus elementos (no hace falta limpiar nada durante las navegaciones de Hotwired Turbo). La API de datos usa **controladores delegados a nivel del documento**; por eso, los controles dentro de contenido insertado después de cargar la página —fragmentos AJAX o Turbo Frames— funcionan sin volver a inicializarlos.

##### Escuchar eventos de complementos

Cada complemento emite eventos `CustomEvent` propagables en su elemento raíz (la tarjeta, el elemento de navegación o la barra lateral). Escucha los eventos en `document` para recibirlos globalmente o en el propio elemento para limitar su alcance. Las acciones con un evento previo se pueden cancelar mediante `preventDefault()`.

```js
document.addEventListener("expanded.lte.card-widget", (e) => {
  console.log("Tarjeta expandida:", e.target)
})

// Impedir que se elimine la tarjeta hasta que el usuario lo confirme
document.addEventListener("remove.lte.card-widget", (e) => {
  if (!confirm("¿Eliminar esta tarjeta?")) {
    e.preventDefault()
  }
})
```

###### Referencia de nombres de eventos

| Complemento | Antes (cancelable) | Después | Se emite al... |
|---|---|---|---|
| Menú lateral | `open.lte.push-menu` | `opened.lte.push-menu` | Se expande la barra lateral. |
| Menú lateral | `collapse.lte.push-menu` | `collapsed.lte.push-menu` | Se contrae la barra lateral. |
| Treeview | `expand.lte.treeview` | `expanded.lte.treeview` | Se abre un submenú (el evento final se emite después de la animación). |
| Treeview | `collapse.lte.treeview` | `collapsed.lte.treeview` | Se cierra un submenú (el evento final se emite después de la animación). |
| Treeview | — | `load.lte.treeview` | Se detecta un submenú abierto al cargar la página. |
| CardWidget | `expand.lte.card-widget` | `expanded.lte.card-widget` | Se expande una tarjeta (el evento final se emite después de la animación). |
| CardWidget | `collapse.lte.card-widget` | `collapsed.lte.card-widget` | Se contrae una tarjeta (el evento final se emite después de la animación). |
| CardWidget | `remove.lte.card-widget` | `removed.lte.card-widget` | Se elimina una tarjeta (sale del DOM después de `removed`). |
| CardWidget | — | `maximized.lte.card-widget` | Se maximiza una tarjeta. |
| CardWidget | — | `minimized.lte.card-widget` | Se restaura una tarjeta maximizada. |
| DirectChat | — | `expanded.lte.direct-chat` | Se abre el panel de contactos. |
| DirectChat | — | `collapsed.lte.direct-chat` | Se cierra el panel de contactos. |
| FullScreen | — | `maximized.lte.fullscreen` | Se activa el modo de pantalla completa. |
| FullScreen | — | `minimized.lte.fullscreen` | Se desactiva el modo de pantalla completa. |
| SidebarSearch | — | `filtered.lte.sidebar-search` | Se filtra el menú (`detail: { query, matches }`; `matches` vale `-1` al borrar el filtro). |
| ColorMode | — | `changed.lte.color-mode` | Cambia el tema (`detail: { theme, resolved }`; se emite en `document`). |

Todos los eventos se propagan (desde la versión 4.1). Los eventos «después» de las acciones animadas se emiten cuando termina la animación, no cuando empieza.

##### Configurar mediante atributos de datos

Algunos complementos leen la configuración de atributos `data-*` en su elemento de destino:

```html
<!-- Treeview: sin acordeón (se pueden abrir varios submenús a la vez) -->
<ul class="nav sidebar-menu" data-lte-toggle="treeview" data-accordion="false">…</ul>

<!-- Treeview: velocidad de animación personalizada -->
<ul class="nav sidebar-menu" data-lte-toggle="treeview" data-animation-speed="500">…</ul>

<!-- Barra lateral: activar persistencia en localStorage (desactivada de forma predeterminada) -->
<aside class="app-sidebar" data-enable-persistence="true">…</aside>

<!-- Barra lateral: personalizar el punto de quiebre para móviles -->
<aside class="app-sidebar" data-sidebar-breakpoint="768">…</aside>
```

La página de referencia de cada complemento documenta los atributos compatibles.

##### Clases CSS administradas por los complementos

Los complementos alternan un conjunto reducido de clases CSS que también puedes personalizar o usar como disparadores:

| Clase | La establece | Dónde | Significado |
|---|---|---|---|
| `sidebar-collapse` | Menú lateral | `<body>` | Barra lateral contraída (modo compacto de escritorio o cerrada en móvil). |
| `sidebar-open` | Menú lateral | `<body>` | Barra lateral abierta explícitamente por el usuario en móvil. |
| `sidebar-mini` | Menú lateral | `<body>` | Modo compacto de barra lateral activo. |
| `menu-open` | Treeview | `.nav-item` | El submenú está expandido. |
| `collapsed-card` | CardWidget | `.card` | Cuerpos y pies de tarjeta contraídos. |
| `maximized-card` | CardWidget | `<html>` y `.card` | Tarjeta en modo de pantalla completa. |
| `direct-chat-contacts-open` | DirectChat | `.direct-chat` | Panel de contactos visible. |
| `hold-transition` | Layout | `<body>` | Transiciones desactivadas brevemente (por ejemplo, durante un cambio de tamaño). |
| `app-loaded` | Layout | `<body>` | Terminó la animación inicial de carga de la página. |
| `reduce-motion` | AccessibilityManager | `<body>` | Se detectó `prefers-reduced-motion` del sistema operativo. |
| `menu-open` | SidebarSearch | `.nav-item` | Submenú expandido para mostrar una coincidencia (se restaura al borrar el filtro). |

##### Producción y código fuente

Los complementos están en [`src/ts/`](https://github.com/ColorlibHQ/master/src/ts) como módulos TypeScript. El archivo publicado `dist/js/adminlte.js` es un paquete Rollup con los ocho, exportados bajo el espacio de nombres `adminlte` (UMD) o como importaciones con nombre (ESM).

Si solo necesitas uno o dos complementos y quieres reducir el tamaño del paquete, importa módulos individuales desde `node_modules/admin-lte/src/ts/` para que tree-shaking los elimine cuando no se usen. Necesitarás TypeScript en tus herramientas de compilación.
