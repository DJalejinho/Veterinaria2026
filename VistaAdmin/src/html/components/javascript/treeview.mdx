El complemento Treeview convierte una lista anidada en un árbol contraíble cuyos submenús se expanden y contraen al hacer clic. Es el componente que controla la navegación lateral de los paneles de demostración.

##### Uso

###### API de datos

Añade `data-lte-toggle="treeview"` al elemento `<ul>` o `<ol>` principal. Dentro de él, marca con `.nav-item` los elementos que tengan hijos y coloca el submenú en otro `<ul class="nav-treeview">` anidado:

```html
<ul class="nav sidebar-menu flex-column" data-lte-toggle="treeview" role="menu">
  <li class="nav-item">
    <a class="nav-link" href="#">
      <i class="nav-icon bi bi-speedometer"></i>
      <p>Panel</p>
    </a>
  </li>
  <li class="nav-item">
    <a href="#" class="nav-link">
      <i class="nav-icon bi bi-folder"></i>
      <p>
        Informes
        <i class="nav-arrow bi bi-chevron-right"></i>
      </p>
    </a>
    <ul class="nav nav-treeview">
      <li class="nav-item">
        <a href="#" class="nav-link"><i class="nav-icon bi bi-circle"></i><p>Ventas</p></a>
      </li>
      <li class="nav-item">
        <a href="#" class="nav-link"><i class="nav-icon bi bi-circle"></i><p>Tráfico</p></a>
      </li>
    </ul>
  </li>
</ul>
```

Para que un submenú aparezca expandido desde el inicio, añade `menu-open` a su `.nav-item`.

##### Configuración

Configúralo mediante atributos `data-*` en el `<ul>` principal:

| Atributo | Valor predeterminado | Descripción |
|---|---|---|
| `data-accordion` | `true` | Cierra los demás submenús abiertos cuando se abre uno. Usa `false` para permitir que varios submenús estén abiertos a la vez. |
| `data-animation-speed` | `300` | Duración de la animación deslizante en milisegundos. Usa `0` para desactivarla. |

```html
<!-- Modo sin acordeón: varios submenús pueden permanecer abiertos -->
<ul class="nav sidebar-menu" data-lte-toggle="treeview" data-accordion="false">
  …
</ul>

<!-- Animación más rápida -->
<ul class="nav sidebar-menu" data-lte-toggle="treeview" data-animation-speed="150">
  …
</ul>
```

##### Clases CSS

| Clase | Se aplica a | Descripción |
|---|---|---|
| `menu-open` | `.nav-item` (elemento principal de un submenú) | El submenú está expandido. |
| `nav-treeview` | `<ul>` (anidado) | Marca un submenú para que el complemento lo reconozca. |
| `nav-arrow` | `<i>` dentro de `.nav-link` | Icono de flecha que gira al abrir el submenú. |

##### Eventos

| Evento | Descripción |
|---|---|
| `expanded.lte.treeview` | Se emite en `.nav-item` al abrir su submenú. |
| `collapsed.lte.treeview` | Se emite en `.nav-item` al cerrar su submenú. |
| `load.lte.treeview` | Se emite una vez por carga de página cuando algún submenú ya está expandido mediante la clase `menu-open`. |

```js
document.addEventListener("expanded.lte.treeview", (e) => {
  console.log("Submenú expandido dentro de:", e.target)
})
```

##### API programática

```js
import { Treeview } from "admin-lte"

const item = document.querySelector(".sidebar-menu .nav-item")
const tv = new Treeview(item, { accordion: true, animationSpeed: 300 })

tv.open()    // expandir el submenú de este elemento
tv.close()   // contraerlo
tv.toggle()  // alternar el estado
```

###### Métodos

| Método | Devuelve | Descripción |
|---|---|---|
| `open()` | `void` | Expande el submenú. Si `accordion` es `true`, primero cierra los submenús hermanos. Emite `expanded.lte.treeview`. |
| `close()` | `void` | Contrae el submenú y emite `collapsed.lte.treeview`. |
| `toggle()` | `void` | Llama a `open()` o `close()` según el estado actual. |
