El complemento PushMenu alterna la barra lateral entre los estados expandido y plegado. Gestiona el diseño adaptable, la persistencia opcional mediante localStorage y la superposición en dispositivos móviles.

##### Uso

Este complemento se activa mediante atributos de datos en la barra lateral y en los botones que la alternan.

**Data API**

Agrega `data-lte-toggle="sidebar"` a cualquier botón o enlace para alternar la barra lateral.

```html
<a href="#" data-lte-toggle="sidebar">Mostrar u ocultar la barra lateral</a>
```

##### Configuración

Configura la barra lateral mediante atributos de datos en el elemento `.app-sidebar`:

| Atributo | Valor predeterminado | Descripción |
|-----------|---------|-------------|
| `data-sidebar-breakpoint` | `991.98` | Ancho de pantalla (px) por debajo del cual se considera que se usa un dispositivo móvil. |
| `data-enable-persistence` | `false` | Guarda el estado de la barra lateral en localStorage entre cargas de página. |

```html
<aside class="app-sidebar" data-enable-persistence="true" data-sidebar-breakpoint="768">
  <!-- contenido de la barra lateral -->
</aside>
```

##### Comportamiento adaptable

- **Escritorio** (por encima del punto de quiebre): la barra lateral aparece expandida. Si la persistencia está activada, se recuerda cuando se pliega.
- **Móvil** (en el punto de quiebre o por debajo): la barra lateral aparece plegada. Al abrirla se muestra una superposición; al pulsarla, la barra lateral se pliega.

##### Clases CSS

| Clase | Se aplica a | Descripción |
|-------|-----------|-------------|
| `sidebar-collapse` | `<body>` | La barra lateral está plegada. |
| `sidebar-open` | `<body>` | La barra lateral se abrió explícitamente en un dispositivo móvil. |
| `sidebar-mini` | `<body>` | Activa el modo compacto de la barra lateral (solo muestra iconos cuando está plegada). |
| `sidebar-without-hover` | `<body>` | Evita que la barra lateral plegada se expanda al pasar el cursor sobre ella. |
| `sidebar-expand-{breakpoint}` | `<body>` | Define el punto de quiebre adaptable (`sm`, `md`, `lg`, `xl`, `xxl`). |

##### Eventos

| Evento | Descripción |
|-------|-------------|
| `open.lte.push-menu` | Se dispara al expandir la barra lateral. |
| `collapse.lte.push-menu` | Se dispara al plegarla. |

Ambos eventos se propagan. Escúchalos en `document` para recibirlos globalmente:

```js
document.addEventListener("open.lte.push-menu", () => {
  console.log("Barra lateral abierta")
})
```

##### API programática

Importa la clase y crea una instancia en cualquier elemento (normalmente, el botón que alterna la barra lateral o `document.body`):

```js
import { PushMenu } from "admin-lte"

const sidebar = new PushMenu(document.querySelector('[data-lte-toggle="sidebar"]'), {
  sidebarBreakpoint: 991.98,
  enablePersistence: false
})
```

###### Métodos

| Método | Devuelve | Descripción |
|---|---|---|
| `toggle()` | `void` | Expande o pliega la barra lateral según su estado actual. Guarda el estado si `enablePersistence` vale `true`. |
| `expand()` | `void` | Expande la barra lateral y dispara `open.lte.push-menu`. |
| `collapse()` | `void` | Pliega la barra lateral y dispara `collapse.lte.push-menu`. |
| `isCollapsed()` | `boolean` | Devuelve `true` si `<body>` tiene la clase `sidebar-collapse`. |
| `isExplicitlyOpen()` | `boolean` | Devuelve `true` si `<body>` tiene `sidebar-open` (en móvil, cuando el usuario abrió la barra lateral). |
| `isMiniMode()` | `boolean` | Devuelve `true` si `<body>` tiene `sidebar-mini`. |
| `isMobileSize()` | `boolean` | Devuelve `true` si `window.innerWidth ≤ sidebarBreakpoint`. |
| `saveSidebarState(state)` | `void` | Guarda manualmente el estado en localStorage (`"sidebar-open"` o `"sidebar-collapse"`). |
| `loadSidebarState()` | `void` | Lee el estado de localStorage y lo aplica. |
| `clearSidebarState()` | `void` | Elimina el estado guardado en localStorage. |
| `updateStateByResponsiveLogic()` | `void` | Recalcula el estado según el tamaño de la ventana (pliega la barra en móviles y la expande en escritorio, salvo en modo compacto). Se ejecuta automáticamente al cambiar el tamaño. |

###### Clave de almacenamiento

Cuando `enablePersistence` está activado, el complemento lee y escribe en `localStorage.getItem("lte.sidebar.state")`. El valor guardado puede ser:

- `"sidebar-open"`: el usuario quiere que la barra lateral esté expandida.
- `"sidebar-collapse"`: el usuario quiere que esté plegada.
