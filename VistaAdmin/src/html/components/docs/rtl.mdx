AdminLTE incluye una hoja de estilos RTL (de derecha a izquierda) junto a la versión LTR estándar. Ambas se generan desde el mismo código fuente mediante [`rtlcss`](https://rtlcss.com/). Úsala para árabe, hebreo, persa, urdu y cualquier otro sistema de escritura de derecha a izquierda.

##### Hoja de estilos RTL precompilada

Cada versión publica variantes RTL de todos los archivos CSS:

```text
dist/css/adminlte.css           ← LTR (predeterminado)
dist/css/adminlte.rtl.css       ← RTL
dist/css/adminlte.min.css
dist/css/adminlte.rtl.min.css
```

Las hojas de estilos opcionales también tienen una versión RTL; por ejemplo, el [tema de compatibilidad de Select2](integrations.html#select2-compatibility-theme), se distribuye como `adminlte-select2.rtl.css` / `.rtl.min.css` junto con su versión LTR.

Para cambiar una página a RTL, reemplaza la hoja de estilos y establece `dir="rtl"` en el elemento `<html>`:

```html
<html lang="ar" dir="rtl">
  <head>
    <link rel="stylesheet" href="dist/css/adminlte.rtl.min.css" />
  </head>
  <body class="layout-fixed sidebar-expand-lg bg-body-tertiary">
    <!-- ...el mismo marcado que LTR -->
  </body>
</html>
```

Con eso basta: la barra lateral queda a la derecha, las barras de desplazamiento se invierten, las utilidades de padding y margin se reflejan y Bootstrap Icons conserva la orientación LTR (la mayoría de los iconos no tiene dirección). Consulta un ejemplo en [`layout/layout-rtl.html`](../layout/layout-rtl.html).

##### Atributo `dir="rtl"` de Bootstrap

Al establecer `dir="rtl"` también se activa el sistema de propiedades lógicas de Bootstrap 5.3: `.ms-*` pasa a aplicar margen derecho en lugar de izquierdo; `.float-start` se alinea a la derecha, etc. No necesitas clases de Bootstrap separadas para RTL: los mismos nombres de utilidades sirven en ambas direcciones.

##### Interfaz con varios idiomas

Si tu aplicación muestra contenido RTL dentro de una página LTR (por ejemplo, un bloque de texto árabe dentro de un panel en inglés), puedes limitar `dir="rtl"` a un solo elemento:

```html
<body>
  <!-- LTR app shell -->
  <main dir="rtl" lang="ar">
    <!-- this block only is RTL -->
  </main>
</body>
```

Bootstrap y AdminLTE gestionan correctamente los cambios de dirección anidados: prevalece la dirección del elemento interno.

##### Compilar RTL por tu cuenta

Si compilas AdminLTE desde el código fuente y modificaste SCSS, vuelve a generar el CSS RTL:

```bash
npm run css-compile     # builds LTR
npm run css-prefix      # adds autoprefixer
npm run css-rtl         # genera archivos *.rtl.css a partir de la salida LTR
npm run css-minify
```

Todo el proceso está integrado en `npm run css`; normalmente basta con ejecutar ese comando.

La conversión se realiza con [`postcss`](https://postcss.org/) y [`rtlcss`](https://rtlcss.com/); ambos ya están en devDependencies. Si necesitas excluir una regla específica de la inversión LTR a RTL, usa las directivas de control de rtlcss en tu SCSS:

```scss
.brand-link {
  /*rtl:ignore*/
  margin-left: .5rem;   // conserva el margen izquierdo en LTR y RTL
}
```

##### Qué cambia automáticamente

| Propiedad sensible a la dirección | Comportamiento en RTL |
|---|---|
| `margin-left` / `padding-left` | Se cambia a la derecha |
| `left`, `right` positioning | Se invierte |
| `text-align: left` / `right` | Se invierte |
| Bootstrap `.ms-*`, `.me-*`, `.float-start`, `.float-end` | Se reflejan mediante las propiedades lógicas de Bootstrap |
| `transform: translateX()` | Se invierte el signo |
| Sidebar position | Se ubica a la derecha |
| Dropdown menu open direction | Se invierte automáticamente (Bootstrap lo gestiona) |

##### Qué no cambia

- Bootstrap Icons (SVG glyphs) — la mayoría de los iconos no tiene dirección; las flechas que sí la indican (`bi-arrow-right`, `bi-chevron-right`, etc.) deben cambiarse manualmente por sus variantes `-left`.
- Inline images, charts, and third-party widgets — su diseño interno no responde a `dir`. Revisa si cada integración (ApexCharts, FullCalendar, Tabulator) ofrece una opción RTL.
- Numbers — los dígitos se mantienen LTR incluso en contextos RTL (es el comportamiento bidireccional estándar de Unicode, no un error).

##### Problemas frecuentes

- **La versión RTL minificada de `.min.css` es `.rtl.min.css`, no `.min.rtl.css`.** El orden del nombre importa; el script de compilación genera la primera.
- **No mezcles hojas de estilos LTR y RTL en una misma página**; elige una. Si necesitas una aplicación con ambas direcciones, usa `dir="rtl"` en el subárbol correspondiente y no una hoja aparte.
- **Reflejo de iconos**: al cambiar un icono para RTL, actualiza también su `aria-label` si indica una dirección (por ejemplo, «Página siguiente» debe seguir diciendo «Página siguiente»; solo gira el glifo).
