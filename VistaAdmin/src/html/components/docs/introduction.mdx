## ¿Qué es AdminLTE?

AdminLTE es una plantilla gratuita de panel de administración con licencia MIT, creada con **Bootstrap 5.3.8** y TypeScript nativo (sin jQuery). Incluye diseños adaptables, navegación lateral, modos de color claro/oscuro/automático, compatibilidad con RTL y una colección creciente de páginas de ejemplo: calendario, tablero Kanban, chat, administrador de archivos, facturas, perfil, configuración y más.

Es una *plantilla*, no una biblioteca de componentes. Copia el marcado en tu proyecto (o en las plantillas de tu framework) y personaliza lo que necesites. Bootstrap 5 proporciona los componentes; AdminLTE, la estructura de la aplicación.

Si todavía no has usado AdminLTE, empieza por [Primeros pasos](getting-started.html): allí crearás un panel funcional en unos diez minutos.

## Formas de instalarlo

Elige la opción que mejor se adapte al uso que le darás a AdminLTE:

| Opción | Recomendada para | Tiempo de configuración |
|---|---|---|
| **CDN** | Prototipos, demostraciones y sitios sencillos | 1 minuto |
| **npm + empaquetador** | Aplicaciones de producción y proyectos con frameworks (Laravel, Symfony, Rails) | 5 minutos |
| **Compilación desde el código fuente** | Personalizar variables SCSS, ancho de la barra lateral y puntos de quiebre | 10 minutos |
| **Composer** | Proyectos PHP que usan Packagist en vez de npm | 2 minutos |

### CDN: la opción más rápida

Agrega estos enlaces CSS dentro de `<head>` y las etiquetas de script antes de `</body>`. No requiere instalación ni compilación:

```html
<!-- Dentro de <head> -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.13.1/font/bootstrap-icons.min.css" />
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/overlayscrollbars@2.11.0/styles/overlayscrollbars.min.css" />
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/admin-lte@4.9.1/dist/css/adminlte.min.css" />

<!-- Antes de </body> -->
<script src="https://cdn.jsdelivr.net/npm/@popperjs/core@2.11.8/dist/umd/popper.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/overlayscrollbars@2.11.0/browser/overlayscrollbars.browser.es6.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/admin-lte@4.9.1/dist/js/adminlte.min.js"></script>
```

Después, copia el HTML de cualquier [página de ejemplo](https://github.com/ColorlibHQ/AdminLTE/tree/master/dist) en tu archivo. Consulta [Primeros pasos](getting-started.html) para ver el diseño mínimo necesario.

### npm + empaquetador

Necesitas Node.js 18 o posterior y un empaquetador (Vite, Webpack, Rollup, esbuild, entre otros).

```bash
npm install admin-lte@4.9.1
```

Luego importa el CSS y JavaScript en el punto de entrada de tu aplicación:

```js
// CSS
import "admin-lte/dist/css/adminlte.min.css"
// También importa Bootstrap y el CSS de las dependencias
import "bootstrap-icons/font/bootstrap-icons.css"
import "overlayscrollbars/styles/overlayscrollbars.css"

// JavaScript
import "bootstrap"
import "admin-lte"
```

Yarn y pnpm funcionan de la misma manera: reemplaza el comando de instalación por `yarn add` o `pnpm add`.

### Compilar desde el código fuente

Si quieres personalizar variables SCSS (ancho de la barra lateral, puntos de quiebre o colores de marca), clona el repositorio y compílalo localmente:

```bash
git clone https://github.com/ColorlibHQ/AdminLTE.git
cd AdminLTE
npm install
npm run dev          # servidor de desarrollo con recarga automática en localhost:3000
npm run production   # compilación de producción (limpieza, análisis y compilación)
```

Los archivos compilados se guardan en `dist/`. Edita `src/scss/_variables.scss` o `src/scss/_bootstrap-overrides.scss` y vuelve a ejecutar la compilación. En [Personalización y temas](customization.html) se explican las variables principales.

### Composer

Para proyectos PHP:

```bash
composer require "almasaeed2010/adminlte=4.0.0"
```

El paquete se publica desde el mismo árbol de código fuente; incluye la carpeta `dist/` lista para servir.

## Requisitos previos

| | Mínimo | Recomendado |
|---|---|---|
| Bootstrap | 5.3.0 | 5.3.8 (versión fijada en `package.json`) |
| Node.js | 18 LTS | 22 LTS (versión usada en CI) |
| Navegador | Navegador moderno con actualizaciones continuas | Últimas versiones estables de Chrome, Firefox, Safari o Edge |

AdminLTE 4 **no** es compatible con Internet Explorer. Si necesitas IE11, usa [AdminLTE 3](https://github.com/ColorlibHQ/AdminLTE/releases/tag/v3.2.0) o una versión anterior.
