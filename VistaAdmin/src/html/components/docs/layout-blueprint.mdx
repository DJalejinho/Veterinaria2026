Todas las páginas de AdminLTE siguen la misma estructura: un contenedor con encabezado, barra lateral, área de contenido principal y, opcionalmente, pie de página. Comprender las clases de estas cuatro regiones permite aprovechar el framework y evita luchar contra su estructura.

##### Las cuatro regiones

```text
┌──────────────────────────────────────────┐
│  .app-wrapper                            │
│  ┌────────────────────────────────────┐  │
│  │  .app-header                       │  │ ← topbar / navbar
│  ├──────────┬─────────────────────────┤  │
│  │          │                         │  │
│  │  .app-   │   .app-main             │  │ ← page content
│  │ sidebar  │                         │  │
│  │          │                         │  │
│  ├──────────┴─────────────────────────┤  │
│  │  .app-footer (opcional)            │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

El contenedor usa CSS Grid y sus cuatro elementos secundarios ocupan áreas de la cuadrícula. No necesitas conocer esos detalles para usarlo: basta con seguir el patrón de marcado.

##### Marcado mínimo

```html
<body class="layout-fixed sidebar-expand-lg bg-body-tertiary">
  <div class="app-wrapper">
    <nav class="app-header navbar navbar-expand bg-body">…</nav>
    <aside class="app-sidebar bg-body-secondary shadow" data-bs-theme="dark">…</aside>
    <main class="app-main">…</main>
    <footer class="app-footer">…</footer>
  </div>
</body>
```

El orden dentro de `.app-wrapper` no importa: la plantilla de grid ubica cada elemento según su clase. Elige el orden que resulte más claro.

##### Referencia de regiones

###### `.app-wrapper`

Contenedor raíz. Define la plantilla de grid que ubica el encabezado, la barra lateral, el contenido principal y el pie de página. Siempre va directamente dentro de `<body>`.

Puedes agregar `.compact-mode` aquí (o en cualquier elemento superior) para reducir el espaciado de todo el diseño; es útil en paneles con muchos datos.

###### `.app-header`

Barra superior. Usa las clases navbar de Bootstrap (`navbar navbar-expand bg-body`) para aplicar los estilos. El encabezado contiene el botón que controla la barra lateral; configúralo con `data-lte-toggle="sidebar"`:

```html
<a class="nav-link" data-lte-toggle="sidebar" href="#" role="button">
  <i class="bi bi-list"></i>
</a>
```

De forma predeterminada, el encabezado se desplaza con la página. Agrega `.fixed-header` a `<body>` para fijarlo.

###### `.app-sidebar`

Barra lateral. Siempre contiene dos elementos secundarios: `.sidebar-brand` (logotipo / nombre de la aplicación) y `.sidebar-wrapper` (la región de navegación desplazable).

```html
<aside class="app-sidebar bg-body-secondary shadow" data-bs-theme="dark">
  <div class="sidebar-brand">
    <a href="/" class="brand-link">
      <span class="brand-text fw-light">Mi panel</span>
    </a>
  </div>
  <div class="sidebar-wrapper">
    <nav class="mt-2">
      <ul class="nav sidebar-menu flex-column" data-lte-toggle="treeview" role="menu">
        <!-- elementos de navegación -->
      </ul>
    </nav>
  </div>
</aside>
```

El `data-bs-theme="dark"` en la barra lateral produce el aspecto de barra oscura sobre página clara de las demostraciones. Quítalo para obtener una barra lateral clara.

###### `.app-main`

Región de contenido de la página. Casi siempre contiene dos elementos secundarios:

```html
<main class="app-main">
  <div class="app-content-header">
    <!-- título de página y ruta de navegación -->
  </div>
  <div class="app-content">
    <!-- contenido de la página: tarjetas, tablas, gráficos, etc. -->
  </div>
</main>
```

`.app-content-header` es la franja del título, normalmente un `<h3>` y una ruta de navegación en la misma fila. `.app-content` contiene todo lo que aparece debajo. Ambos deberían envolver sus elementos con `.container-fluid` (o `.container` para limitar el ancho).

###### `.app-footer` (opcional)

Franja de pie de página en la parte inferior del contenedor:

```html
<footer class="app-footer">
  <div class="float-end d-none d-sm-inline">Versión 4.0.0</div>
  <strong>&copy; 2026 Tu empresa</strong>
</footer>
```

Agrega `.fixed-footer` a `<body>` para fijarlo en la parte inferior de la ventana.

##### Modificadores de diseño aplicados al body

El comportamiento del diseño se controla principalmente mediante clases en `<body>`, y no en `.app-wrapper`. Modificadores disponibles:

| Clase | Función |
|---|---|
| `layout-fixed` | La barra lateral tiene su propia barra de desplazamiento; solo `.app-main` se desplaza con la página |
| `fixed-header` | Fija `.app-header` en la parte superior; desde v4.0.0 también fija la barra lateral |
| `fixed-footer` | Fija `.app-footer` en la parte inferior |
| `sidebar-expand-{sm,md,lg,xl,xxl}` | Punto de interrupción en el que la barra lateral pasa de estar fuera del lienzo (móvil) a mostrarse en línea (escritorio). `lg` es el valor predeterminado en las demostraciones. |
| `sidebar-mini` | Contrae la barra lateral y deja solo los iconos |
| `sidebar-mini sidebar-collapse` | Inicia la página con la barra lateral mini contraída |
| `sidebar-without-hover` | Desactiva la expansión automática al pasar el cursor sobre la barra lateral mini |
| `layout-rtl` | Invierte el diseño para idiomas de derecha a izquierda (también requiere `.rtl.css` y `dir="rtl"`; consulta [Compatibilidad con RTL](rtl.html)) |

Estas opciones se pueden combinar. Los paneles de demostración usan `class="layout-fixed sidebar-expand-lg bg-body-tertiary"`; fija la barra lateral y establece su punto de interrupción de escritorio en `lg` (≥992px).

##### Comportamiento adaptable

En el punto de interrupción `sidebar-expand-*` o superior, la barra lateral se muestra **en línea**, dentro de la cuadrícula junto a `.app-main`. Por debajo de ese punto, pasa a ser **fuera del lienzo**: permanece oculta y se desliza desde la izquierda al pulsar el botón de menú.

Clases específicas para dispositivos móviles:

| Clase | Cuándo se aplica | Efecto |
|---|---|---|
| `sidebar-open` | Cuerpo — cuando la persona usuaria abre explícitamente la barra lateral móvil | Desliza la barra lateral sobre el contenido con una capa superpuesta |
| `sidebar-collapse` | Cuerpo — se establece automáticamente al cerrar la barra lateral móvil | Oculta la barra lateral |

Estas opciones se gestionan mediante el [Complemento Menú lateral](javascript/pushmenu.html); no tienes que escribirlas manualmente.

##### Errores frecuentes

- **Olvidar `.container-fluid` dentro de `.app-content`**; el contenido queda pegado al borde de la pantalla. Envuelve las tarjetas en un contenedor.
- **Colocar el control de la barra lateral fuera de `.app-header`**; seguirá funcionando, pero los estilos esperan que esté dentro de la barra de navegación.
- **Mezclar las clases `.app-*` y `.main-*`**: `.main-*` corresponde a los nombres de AdminLTE 3. No las combines. Consulta [Migración desde v3](migration.html).
- **Usar `position: fixed` en un elemento dentro de `.app-main`**: `layout-fixed` ya establece `overflow: auto` en `.app-main`. Los elementos secundarios con `position: fixed` pueden comportarse de forma inesperada. Usa posicionamiento sticky.
- **Definir manualmente el ancho de la barra lateral en CSS personalizado**; el ancho de la barra lateral está disponible mediante la variable SCSS `$lte-sidebar-width`. Si necesitas conocerlo desde JavaScript, consulta el ancho calculado del elemento `.app-sidebar`.
