AdminLTE incluye deliberadamente pocas dependencias. En lugar de agregar todos los widgets de formularios y bibliotecas de gráficos, recomendamos bibliotecas de terceros destacadas que puedes integrar cuando las necesites. Todas las bibliotecas de esta lista tienen licencia **MIT**, reciben **mantenimiento activo** y **no dependen de jQuery**.

Cada sección incluye un fragmento de instalación mediante CDN y el JavaScript mínimo para configurarlo. Si usas un empaquetador, puedes reemplazar las URL del CDN por instalaciones de npm.

> **Sobre los números de versión:** cada URL del CDN fija una versión específica (por ejemplo, `@4.6.13`) para que los fragmentos sean reproducibles. Esas versiones estaban vigentes al publicarse la última versión de AdminLTE, pero las bibliotecas de terceros se actualizan por separado. Antes de copiar un fragmento a producción, consulta el sitio oficial de la biblioteca, enlazado en cada sección, y considera alojar una copia propia en lugar de depender del CDN a largo plazo.

###### Selección múltiple y etiquetas: Tom Select

[Tom Select](https://tom-select.js.org/) es una reescritura de Selectize en JavaScript vanilla. Es una buena opción para listas de selección con búsqueda, campos de etiquetas y autocompletado con datos remotos.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/tom-select@2.6.1/dist/css/tom-select.bootstrap5.min.css" />
<script src="https://cdn.jsdelivr.net/npm/tom-select@2.6.1/dist/js/tom-select.complete.min.js"></script>

  <option value="dev">Desarrollo</option>
  <option value="qa">QA</option>
</select>

<script>
  new TomSelect("#tags", { plugins: ["remove_button"] })
</script>
```

Incluye el tema `tom-select.bootstrap5.min.css`, que coincide con el aspecto de los controles de formulario de Bootstrap.

**Datos remotos.** Para listas conectadas a una base de datos en vez de a opciones estáticas, realiza la solicitud dentro de `load()`. Tom Select aplica un debounce mediante `loadThrottle` (300 ms de forma predeterminada), y el plugin `virtual_scroll` carga más resultados a medida que se desplaza la lista:

```js
let inFlight = null

new TomSelect("#reviewer", {
  valueField: "id",
  labelField: "name",
  searchField: ["name"],
  loadThrottle: 300,                      // espera entre búsquedas, integrada
  plugins: ["virtual_scroll"],            // paginación con desplazamiento infinito
  firstUrl: (query) => `/api/users?q=${encodeURIComponent(query)}&page=1`,
  load(query, callback) {
    inFlight?.abort()                     // cancelar la solicitud anterior
    inFlight = new AbortController()

    fetch(this.getUrl(query), { signal: inFlight.signal })
      .then((response) => response.json())
      .then((json) => {
        if (json.next) {
          this.setNextUrl(query, json.next)
        }
        callback(json.results)
      })
      .catch((error) => {
        if (error.name !== "AbortError") {
          callback()
        }
      })
  }
})
```

`forms/advanced.html` ejecuta este mismo patrón contra un endpoint simulado. Reemplaza el simulador por una llamada `fetch()` para usarlo sin otros cambios.

###### Si vienes de Select2

[Select2](https://select2.org/) aún recibe mantenimiento (la versión 4.1.0 se publicó en 2026), pero sigue siendo un plugin de jQuery: su envoltorio UMD requiere jQuery y no existe una compilación que prescinda de él. Por eso AdminLTE 4 recomienda Tom Select, que ofrece funciones similares y ocupa cerca de 20 kB comprimidos con gzip, frente a los aproximadamente 50 kB de Select2 contando jQuery.

La correspondencia entre las API es directa:

| Select2 | Tom Select |
|---|---|
| `$("#x").select2()` | `new TomSelect("#x")` |
| `$("#x").select2({ tags: true })` | `new TomSelect("#x", { create: true })` |
| `allowClear: true` | `plugins: ["clear_button"]` |
| `closeOnSelect: false` | `closeAfterSelect: false` |
| `maximumSelectionLength: 3` | `maxItems: 3` |
| `minimumInputLength: 2` | `shouldLoad: (q) => q.length >= 2` |
| `ajax: { url, delay: 250 }` | `load(query, callback)` + `loadThrottle: 250` |
| `ajax: { …, processResults }` | `valueField` / `labelField` / `searchField` |
| desplazamiento infinito (`pagination.more`) | `plugins: ["virtual_scroll"]` + `setNextUrl()` |
| `templateResult` / `templateSelection` | `render: { option, item }` |
| `dropdownParent: $("#modal")` | *(no hace falta: el menú se muestra dentro del elemento)* |
| `$("#x").val("2").trigger("change")` | `ts.setValue("2")` |
| `$("#x").val()` | `ts.getValue()` |
| `$("#x").on("select2:select", fn)` | `ts.on("item_add", fn)` |
| `$("#x").on("change", fn)` | `ts.on("change", fn)` |
| `$("#x").select2("open")` | `ts.open()` |
| `$("#x").prop("disabled", true)` | `ts.disable()` |
| `$("#x").select2("destroy")` | `ts.destroy()` |
| `$("#x").empty().select2({ data })` | `ts.clearOptions(); ts.addOptions(data)` |

Puedes consultar esta tabla y probar el código en la demostración [Elementos avanzados](../forms/advanced.html#select2).

**Si necesitas conservar Select2**, AdminLTE incluye una hoja de compatibilidad que solo aplica estilos; consulta el [tema de compatibilidad con Select2](#select2-compatibility-theme) más abajo.

###### Tema de compatibilidad con Select2

Algunos proyectos no pueden prescindir de Select2: por ejemplo, un ERP con cientos de formularios renderizados en el servidor, un plugin de proveedor que lo inicializa automáticamente o un equipo que todavía no está listo para migrar. AdminLTE no incluye Select2 ni jQuery, pero sí ofrece un **tema de compatibilidad solo CSS** para que tu instalación de Select2 adopte las dimensiones de formularios, el indicador de foco, los estados de validación y el modo oscuro `data-bs-theme` de Bootstrap 5.3.

- **`dist/css/adminlte-select2.css`** (+ `.min.css`, `.rtl.css`, `.rtl.min.css`)
- No agrega JavaScript ni jQuery, y tampoco modifica `adminlte.css`: solo tienes que cargar una hoja de estilos adicional.

Cárgalo **después** de `select2.css`:

```html
<link rel="stylesheet" href="path/to/adminlte.min.css" />
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/select2@4.1.0/dist/css/select2.min.css" />
<link rel="stylesheet" href="path/to/adminlte-select2.min.css" />

<select id="country" class="form-select">
  <option value="">Selecciona un país…</option>
  <option value="lv">Letonia</option>
</select>

<script src="https://cdn.jsdelivr.net/npm/jquery@3.7.1/dist/jquery.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/select2@4.1.0/dist/js/select2.min.js"></script>
<script>
  $("#country").select2({ width: "100%" })
</script>
```

El tema se encarga de lo siguiente:

| | |
|---|---|
| Medidas | La altura, el relleno, el tamaño de fuente y el radio del borde coinciden exactamente con `.form-select` |
| Tamaños | Se respetan `.form-select-sm` y `.form-select-lg` en el `<select>` original |
| Foco | Usa el anillo de foco de Bootstrap en lugar del contorno negro de Select2 |
| Modo oscuro | Sigue `data-bs-theme`, también en el menú desplegable agregado al `body` |
| Validación | `.is-invalid` y `.is-valid` en el `<select>` original cambian el color del contenedor |
| Selección múltiple | Las opciones se muestran como insignias secundarias de Bootstrap |
| Grupos de campos | Ajusta las esquinas y el tamaño flexible de `.input-group` |
| Modales | Eleva el `z-index` del menú por encima de `.modal`. Resuelve uno de los errores más reportados al combinar Select2 con Bootstrap 5, por lo que ya no hace falta `dropdownParent` |
| RTL | Se genera automáticamente junto con el resto del CSS |

¿Usas un empaquetador? Puedes acceder a la hoja compilada mediante el mapa `exports` del paquete, después del CSS propio de Select2:

```js
import "admin-lte/dist/css/adminlte.min.css"
import "select2/dist/css/select2.min.css"
import "admin-lte/dist/css/adminlte-select2.min.css"
```

¿Compilas tu propio Sass? Importa el partial después de AdminLTE, que ya habrá cargado las variables y los mixins de Bootstrap que necesita:

```scss
@import "node_modules/admin-lte/src/scss/adminlte";
@import "node_modules/admin-lte/src/scss/compat/select2";
```

El tema sigue el marcado de Select2 4.1.x (también cubre el marcado choice-remove de la versión 4.0.x). Solo aplica estilos: los errores del propio Select2 deben corregirse en Select2, y ninguno de los ports oficiales de AdminLTE para frameworks (Vue, React, Django, Laravel) puede usar un plugin de jQuery.

##### Nota sobre el empaquetado

Los ejemplos anteriores usan CDN de jsDelivr para facilitar la copia y el uso. Para producción, conviene elegir una de estas opciones:

1. **Instalar con npm y usar un empaquetador** (Vite, Webpack, Rollup): ofrece tree-shaking y permite fijar versiones.
2. **Alojar los archivos en tu servidor**: evita que una caída del CDN interrumpa el servicio.
3. **Usar CDN con hashes `integrity`**: adecuado para prototipos y demostraciones.

AdminLTE no incluye estas bibliotecas; mantener reducido el tamaño del framework es una decisión intencional. Elige las que necesites y omite las demás.
