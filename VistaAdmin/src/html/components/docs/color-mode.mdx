AdminLTE es compatible de forma nativa con los modos de color de Bootstrap 5.3 (claro, oscuro y automático). Desde la versión 4.1, el selector está incluido en `adminlte.js` como módulo **ColorMode**; ya no necesitas copiar un script en tus páginas.

##### Cómo funciona

- El modo elegido se guarda en `localStorage` bajo la clave `lte-theme`.
- `auto` sigue el valor `prefers-color-scheme` del sistema operativo y se actualiza cuando cambia su preferencia.
- El modo resuelto se aplica como `data-bs-theme="light|dark"` en `<html>`, para que todos los componentes de Bootstrap y AdminLTE se adapten automáticamente.

El modo se determina a partir de estas fuentes, en orden:

1. **Elección guardada del visitante**: `localStorage.lte-theme`, que se escribe cuando pulsa un control. Tiene prioridad porque refleja su elección en este dispositivo.
2. **Tema declarado por la página**: valor de `data-bs-theme` en `<html>` cuando se sirve. Úsalo para aplicar una preferencia de usuario obtenida de una cookie o de su registro; se mantiene aunque cambie la preferencia del sistema.
3. **Preferencia del sistema operativo**: `prefers-color-scheme`, que se sigue en tiempo real si las opciones anteriores no especifican una elección.

Solo se reconocen `light`, `dark` y `auto`. ColorMode no puede resolver un nombre de tema personalizado de Bootstrap en `data-bs-theme` y lo ignora. Consulta la sección *Desactivar la función*.

##### Marcado

Agrega botones de alternancia en cualquier parte mediante `data-bs-theme-value`; el módulo los enlaza automáticamente. También puedes usar elementos `data-lte-theme-icon` como indicadores de la opción actual, tal como hace la demostración en el encabezado:

```html
<li class="nav-item dropdown">
  <a
    class="nav-link"
    href="#"
    id="bd-theme"
    aria-label="Cambiar esquema de color"
    data-bs-toggle="dropdown"
    aria-expanded="false"
  >
    <i class="bi bi-sun-fill" data-lte-theme-icon="light"></i>
    <i class="bi bi-moon-fill d-none" data-lte-theme-icon="dark"></i>
    <i class="bi bi-circle-half d-none" data-lte-theme-icon="auto"></i>
  </a>
  <ul class="dropdown-menu dropdown-menu-end" aria-labelledby="bd-theme">
    <li>
      <button type="button" class="dropdown-item d-flex align-items-center" data-bs-theme-value="light" aria-pressed="false">
        <i class="bi bi-sun-fill me-2"></i>
        Claro
        <i class="bi bi-check-lg ms-auto d-none"></i>
      </button>
    </li>
    <li>
      <button type="button" class="dropdown-item d-flex align-items-center" data-bs-theme-value="dark" aria-pressed="false">
        <i class="bi bi-moon-fill me-2"></i>
        Oscuro
        <i class="bi bi-check-lg ms-auto d-none"></i>
      </button>
    </li>
    <li>
      <button type="button" class="dropdown-item d-flex align-items-center active" data-bs-theme-value="auto" aria-pressed="true">
        <i class="bi bi-circle-half me-2"></i>
        Automático
        <i class="bi bi-check-lg ms-auto d-none"></i>
      </button>
    </li>
  </ul>
</li>
```

El módulo mantiene sincronizados la clase `active`, el estado `aria-pressed` y las marcas `.bi-check-lg` de todos los botones `[data-bs-theme-value]`.

##### API de JavaScript

```js
import { ColorMode } from "admin-lte"

const colorMode = new ColorMode()

colorMode.getPreferredTheme() // "light" | "dark" | "auto" — la opción efectiva
colorMode.getStoredTheme()    // lo que eligió la persona usuaria, o null
colorMode.getMarkupTheme()    // lo que declaró la página en <html>, o null
colorMode.setTheme("dark")    // apply + persist + sync toggles

// Reacciona a los cambios (el evento se envía en document).
document.addEventListener("changed.lte.color-mode", (event) => {
  console.log(event.detail.theme)    // elección del usuario: "light" | "dark" | "auto"
  console.log(event.detail.resolved) // tema aplicado: "light" | "dark"
})
```

##### Evitar el destello del tema incorrecto

El módulo se ejecuta cuando el DOM está listo, por lo que las páginas también deben aplicar el tema guardado *antes del primer renderizado*, mediante un pequeño fragmento en línea en `<head>` (esta parte debe permanecer en línea; consulta `#6043`):

```html
<script>
  (() => {
    "use strict"
    const root = document.documentElement
    if (root.getAttribute("data-lte-color-mode") === "off") return
    let stored = null
    try { stored = localStorage.getItem("lte-theme") } catch {}
    const authored = root.getAttribute("data-bs-theme")
    let resolved = "light"
    if (stored === "dark" || stored === "light") resolved = stored
    else if (authored === "dark" || authored === "light") resolved = authored
    else if (matchMedia("(prefers-color-scheme: dark)").matches) resolved = "dark"
    root.setAttribute("data-bs-theme", resolved)
    root.style.colorScheme = resolved
    if (resolved !== authored) root.setAttribute("data-lte-theme-resolved", "")
  })()
</script>
```

Sigue el mismo orden de prioridad que el módulo, por lo que no sobrescribe antes del renderizado un tema generado en el servidor. La última línea es importante: marca el valor que calculó el fragmento para que el módulo no lo confunda con un tema declarado por la página ni deje de seguir la preferencia del sistema operativo.

##### Temas generados en el servidor

Si guardas la preferencia de cada usuario en el servidor, inclúyela en `<html>`. El módulo la conservará durante la carga y ante cambios en la preferencia del sistema operativo:

```html
<html lang="es" data-bs-theme="dark">
```

Ese valor funciona como predeterminado: cuando el visitante pulsa un control, su elección se guarda y pasa a tener prioridad en ese dispositivo. Borra `lte-theme` de `localStorage` para volver a usar el valor del servidor.

##### Desactivar la función

Las aplicaciones que gestionan sus propios temas (un tema personalizado de Bootstrap o su propio selector) pueden desactivar el módulo por completo:

```html
<html lang="es" data-lte-color-mode="off">
```

En ese caso, ColorMode nunca modifica `data-bs-theme`: ni al cargar, ni al pulsar un control `[data-bs-theme-value]`, ni cuando cambia la preferencia del sistema operativo. El fragmento en línea anterior también respeta esta opción, así que el tema no cambia antes del primer renderizado. Tu código conserva el control de `<html data-bs-theme>`.

##### Modos de color por sección

`data-bs-theme` también funciona en cualquier elemento, no solo en `<html>`. Por ejemplo, puedes mantener oscura la barra lateral dentro de un diseño claro:

```html
<aside class="app-sidebar" data-bs-theme="dark">...</aside>
```
