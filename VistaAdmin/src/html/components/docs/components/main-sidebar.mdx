## Logotipo alternativo

Puedes usar dos imágenes de logotipo en lugar de un logotipo con texto; solo tienes que cambiar el marcado por este:

```html
<div class="sidebar-brand">
  <a href="./index.html" class="brand-link logo-switch">
    <img
      src="./assets/img/AdminLTELogo.png"
      alt="Logotipo pequeño de AdminLTE"
      class="brand-image-xl logo-xs opacity-75 shadow"
    />
    <img
      src="./assets/img/AdminLTEFullLogo.png"
      alt="Logotipo de AdminLTE Large"
      class="brand-image-xs logo-xl opacity-75"
    />
  </a>
</div>
```
