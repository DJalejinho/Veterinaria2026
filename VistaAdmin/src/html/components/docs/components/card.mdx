Las tarjetas son el contenedor principal de contenido en AdminLTE. Son [tarjetas de Bootstrap](https://getbootstrap.com/docs/5.3/components/card/) con una sombra adicional, variantes de color, una barra de herramientas en el encabezado y compatibilidad con el [complemento CardWidget](../javascript/card-widget.html), que permite contraerlas, eliminarlas y maximizarlas.

##### Estructura

```html
<div class="card card-primary card-outline">
  <div class="card-header">
    <div class="card-title">Título</div>
    <div class="card-tools">
      <button type="button" class="btn btn-tool" data-lte-toggle="card-collapse" aria-label="Collapse card">
        <i data-lte-icon="expand" class="bi bi-plus-lg"></i>
        <i data-lte-icon="collapse" class="bi bi-dash-lg"></i>
      </button>
    </div>
  </div>
  <div class="card-body">Cuerpo</div>
  <div class="card-footer">Pie de página</div>
</div>
```

| Clase | Descripción |
|---|---|
| `.card` | Contenedor. Añade la sombra de AdminLTE a la tarjeta de Bootstrap. |
| `.card-header` | Franja del encabezado. Su posición relativa permite que `.card-tools` flote en su interior. |
| `.card-title` | Texto del encabezado. Flota a la izquierda con tamaño `1.1rem`; es un estilo, no un encabezado semántico. Usa el elemento que corresponda a la estructura del documento. |
| `.card-tools` | Barra de herramientas alineada a la derecha dentro del encabezado. Compensa el relleno horizontal para que los botones queden al ras. |
| `.btn-tool` | Botón de icono discreto y sin borde para usar dentro de `.card-tools`. Añade `.btn-tool-custom` para conservar tus propios colores. |
| `.card-body` | Área de contenido. |
| `.card-footer` | Franja del pie de página. |

##### Variantes de color

Cada entrada de `$theme-colors` genera una clase `.card-*`. La variante establece dos propiedades personalizadas — `--lte-card-variant-bg` y `--lte-card-variant-color` — que usa el encabezado. Así, `.bg-primary` y `.text-bg-primary` aplican a la tarjeta el mismo color que `.card-primary`.

```html
<div class="card card-primary">…</div>
<div class="card card-success">…</div>
<div class="card card-danger">…</div>
```

Agrega `.card-outline` para convertir el color en un borde superior de 3 px y dejar el encabezado sin color:

```html
<div class="card card-primary card-outline">…</div>
```

##### Estados

Estas clases representan los estados que alterna [CardWidget](../javascript/card-widget.html). Puedes incluir una en el marcado para que la tarjeta aparezca inicialmente contraída.

| Clase | Descripción |
|---|---|
| `.collapsed-card` | Oculta el cuerpo y el pie, y cambia el icono de contraer por el de expandir. |
| `.maximized-card` | Fija la tarjeta a la ventana con el tamaño máximo. AdminLTE también establece esta clase en `<html>` para bloquear el desplazamiento de la página. |
| `.was-collapsed` | CardWidget la establece si la tarjeta estaba contraída al maximizarla; al restaurarla, vuelve a quedar contraída. |
| `.expanding-card` | Está presente durante la animación de expansión. |

La visibilidad de los iconos se adapta automáticamente al estado: `[data-lte-icon="expand"]` se oculta salvo que la tarjeta esté contraída, y `[data-lte-icon="minimize"]` se oculta salvo que esté maximizada. Incluye ambos iconos y deja que CSS elija cuál mostrar.

##### Tarjetas con pestañas

`.card-tabs` coloca `.nav-tabs` en el encabezado y ajusta el borde entre las pestañas y el cuerpo:

```html
<div class="card card-primary card-tabs">
  <div class="card-header p-0 pt-1">
    <ul class="nav nav-tabs" role="tablist">
      <li class="nav-item" role="presentation">
        <button class="nav-link active" data-bs-toggle="pill" data-bs-target="#tab-1" type="button" role="tab">Pestaña 1</button>
      </li>
      <li class="nav-item" role="presentation">
        <button class="nav-link" data-bs-toggle="pill" data-bs-target="#tab-2" type="button" role="tab">Pestaña 2</button>
      </li>
    </ul>
  </div>
  <div class="card-body">
    <div class="tab-content">
      <div class="tab-pane fade show active" id="tab-1" role="tabpanel" tabindex="0">…</div>
      <div class="tab-pane fade" id="tab-2" role="tabpanel" tabindex="0">…</div>
    </div>
  </div>
</div>
```

`.card-outline-tabs` aplica la misma idea a las tarjetas con contorno: la pestaña activa muestra el color de acento en el borde superior, en lugar de la tarjeta.

##### Utilidades

| Clase | Descripción |
|---|---|
| `.height-control` | Limita el cuerpo a `300px` y habilita el desplazamiento. |
| `.card .nav.flex-column` | Una navegación vertical dentro de una tarjeta muestra separadores entre elementos, pero no después del último. Se usa en los [widgets de usuario](miscellaneous.html#social-and-post-widgets). |

##### Variables Sass

| Variable | Valor predeterminado | Descripción |
|---|---|---|
| `$lte-card-shadow` | Sombra de dos capas basada en `--bs-body-color-rgb` | Sombra aplicada a cada `.card`. |
| `$lte-card-title-font-size` | `1.1rem` | Tamaño de `.card-title`. |
| `$lte-card-title-font-weight` | `$font-weight-normal` | Grosor de fuente de `.card-title`. |

##### Notas

- `.card-title` flota, por lo que un `.card-header` que solo contiene el título y las herramientas no tiene altura propia. El mixin clearfix del encabezado la restablece; por el mismo motivo, puedes añadir otros elementos flotantes.
- Las tarjetas anidadas se gestionan correctamente: las reglas para contraer y expandir usan `> .card-header` y `> .card-body`, así que contraer una tarjeta externa no modifica los iconos de las tarjetas internas.
- Si un botón situado en otra parte de la página controla la tarjeta, usa la [API programática](../javascript/card-widget.html#programmatic-api) de CardWidget en lugar de añadir o quitar manualmente las clases de estado. La API también emite los eventos correspondientes.
