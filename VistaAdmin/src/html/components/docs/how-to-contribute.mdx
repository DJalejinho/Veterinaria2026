# Cómo colaborar con AdminLTE

¡Las contribuciones son siempre **bienvenidas y recomendadas**! Si estás empezando, consulta esta [introducción al código abierto](https://youtu.be/GbqSvJs-6W4).

1. **Requisitos para contribuir:**
   - Al contribuir, aceptas otorgar a AdminLTE.io una licencia no exclusiva para usar tu contribución en cualquier contexto que AdminLTE.io considere apropiado.
   - Si usas contenido de terceros, debe contar con una licencia adecuada de [código abierto](https://opensource.org/licenses).
   - Solo se aceptan contribuciones mediante pull requests de GitHub.
   - El código aportado debe funcionar en todos los navegadores compatibles (consulta la sección de compatibilidad).
2. **Instalación:**
   - Crea un fork del repositorio (consulta [esta guía](https://help.github.com/articles/fork-a-repo/)).
   - Clónalo en tu equipo:

   ```bash
   git clone https://github.com/YOUR_USERNAME/AdminLTE.git
   ```

   - Crea una rama nueva a partir de `master`.
3. **Compila los archivos de distribución (`dist`):**
   - Necesitas Node.js 18 o posterior y npm (Node Package Manager).
   - Ejecuta `npm install` para instalar las dependencias.
   - Ejecuta `npm run dev` para iniciar el modo de desarrollo con compilación automática y BrowserSync para la demostración en vivo.
   - Haz cambios solo en la carpeta `./src` o en `package.json`, y únicamente en los archivos necesarios para tu contribución.
   - No modifiques `./dist/**`: contiene archivos compilados y no debe incluirse en los pull requests.
   - Antes de crear un pull request, ejecuta `npm run production` para compilar CSS/JS y comprobar que las páginas funcionen correctamente.
4. Crea un pull request dirigido a la rama `master`.

## Configuración en línea para contribuir con un clic

Puedes usar [Codespaces](https://docs.github.com/en/codespaces), un IDE en línea gratuito para proyectos de código abierto y para trabajar en issues o crear pull requests. Con un clic, iniciará un espacio de trabajo y automáticamente:

- Clonará el repositorio `AdminLTE`.
- Lo abrirá en [Codespaces](https://docs.github.com/en/codespaces) o en [Gitpod](https://gitpod.io/from-referrer/).
- Instalará las dependencias.
- Ejecutará `npm run dev` para iniciar el servidor.
