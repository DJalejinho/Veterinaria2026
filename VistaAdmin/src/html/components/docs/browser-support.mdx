AdminLTE ofrece la misma compatibilidad con navegadores que Bootstrap 5.

> ##### Extracto de la documentación oficial de Bootstrap
>
> Bootstrap es compatible con las **versiones estables más recientes** de los principales navegadores y plataformas.
>
> Consulta más detalles [aquí](https://getbootstrap.com/docs/5.0/getting-started/browsers-devices/#supported-browsers).

Puedes consultar los navegadores y las versiones compatibles en nuestro archivo [.browserslistrc](https://github.com/ColorlibHQ/AdminLTE/blob/master/.browserslistrc):

```
# https://github.com/browserslist/browserslist#readme

>= 0.5%
last 2 major versions
not dead
Chrome >= 60
Firefox >= 60
Firefox ESR
iOS >= 12
Safari >= 12
not Explorer <= 11
```
